# 작업 메모

- 독자 진단: **혼합형으로 가정**(요청: 수학이 어렵고 행렬·벡터를 처음 공부하는 학생). 수식 막힘형 처방을 먼저 적용 — 기호는 하루의 질문 상자에서 하나씩, 수식 앞에 그림·작은 숫자, 행렬은 "더 알고 싶은 분" 접기 상자에만.
- 원자료 확인: eeanimation Part 4 예제(μ₁ = (1, 1), μ₂ = (3, 2), Σ = I → w = (2, 1), 합격선 5.5, x = (2, 2) → 6 → Class 2)는 검산 결과 맞음. 깃발 거리(1 대 1.41)로도 같은 결론. MLTut 인포그래픽의 KNN 예시 점 배치는 그림에서 읽어 옮겼고(대략값), 바꾼 값은 없음.
- 용어: 사용자 요청에 따라 단위는 "챕터"·"파트". 금지어 전체 검색 0건(금지된 독자 호칭, 스킬 용어 규칙의 금지 표현).
- 요청 문장의 "위상수학이 꽤 어려운 과목이기 때문에"는 이번 주제(분류·커널)를 가리키는 것으로 읽고, 챕터를 17개(파트 4개)로 잘게 나눔.
- 라운드 데이터는 시드를 골라 두 방법의 차이가 잘 보이게 만든 교육용 예시이며, 대회 규칙 아래에 그 사실을 밝힘.

# 페르소나 검사 — 행렬·벡터를 처음 공부하는 학생 관점 중심

## 0. 대상 요약
운동장 지도 비유로 LDA → KNN → SVM·SVC → 커널을 17개 챕터, 4개 파트로 풀고, 파트마다 초파리 팀과 주판봇 팀의 분류 라운드(박사 심판)를 둔 시리즈. 목차(기호 사전·대회 규칙), 파트 1~4, 실전 연습장(4개 사업장, 미션 12개) 6쪽. 핵심 메시지는 "모든 방법은 '가까우면 같은 편'을 서로 다른 거리로 쓴 것".

## 5. 정리
입문 학생(A·B)은 비유와 하루의 질문 상자 덕분에 파트 1~2를 무리 없이 따라갔지만, 파트 4에서 √2와 exp처럼 "왜 이게 붙지?"가 설명되지 않은 기호에서 멈췄습니다. 전문가(F)와 실무자(E)는 숫자와 이름 정리의 정확성을 높게 봤고, 문장 하나의 조건 위치와 데이터 고지를 지적했습니다. 교사(D)와 직장인(C)은 구성은 좋게 봤지만 퀴즈 수, 접근성, 현장 사례의 깊이를 아쉬워했습니다. 비용 대비 효과가 큰 1~6순위는 이번에 모두 반영했고, 보완 후 입문자와 전문가 점수 차는 0.5점 이내입니다. 7순위(방향키 이동)와 8순위 중 쪽지시험도 이어서 반영했고, 남은 것은 교사용 가이드와 9순위(현장 사례 보강)입니다.
